# 🏎️ Car Pro
থ্রিডি কার রেসিং গেম (Three.js + Capacitor) — Powered by Mahin

## APK বানানোর নিয়ম
1. এই ফোল্ডারের সব ফাইল GitHub repository-তে push করো (`main` branch)।
2. **Actions** ট্যাবে "Build Car Pro APK" নিজে থেকে চলবে (বা Run workflow চাপো)।
3. শেষ হলে রান পেজের নিচে **Artifacts → CarPro-APK** থেকে `CarPro.apk` ডাউনলোড করো।
4. `git tag v1.0.0 && git push --tags` দিলে Releases-এও APK আপলোড হবে।
